================================================================================
A. DESKRIPSI DAN LATAR BELAKANG
================================================================================
Perkembangan teknologi Internet of Things (IoT) serta sistem kendali berbasis jaringan 
memungkinkan robot manipulator dioperasikan tanpa kabel melalui antarmuka web. 
Pada sistem konvensional, Dobot Magician dikendalikan melalui DobotStudio yang 
hanya berjalan secara lokal pada PC via kabel USB.

Pada proyek ujian praktik ini, dirancang dan diuji sistem kendali nirkabel 
berbasis Web Smartphone (Continuous Jog Controller V2) dengan arsitektur 
terdistribusi client-server. Smartphone berfungsi sebagai antarmuka pengguna 
(Frontend Web) yang terhubung melalui Wi-Fi ke laptop pengontrol (Backend Flask 
dan TCP Receiver) yang terhubung langsung ke Dobot Magician via komunikasi serial USB.

Sistem menyediakan fungsionalitas komprehensif yang mencakup:
1. Deteksi otomatis COM Port dan manajemen status koneksi robot (CONNECT/DISCONNECT).
2. Kalibrasi posisi nol absolut (Homing / HOME Routine).
3. Pengendalian Continuous JOG pada sumbu kartesian X, Y, dan Z (Hold to Move, 
   Release to Stop).
4. Penghentian darurat perangkat lunak (STOP / Emergency Software Interruption).
5. Konfigurasi kecepatan gerak (Speed Setting) untuk sumbu X, Y, dan Z (1 - 100 mm/s).
6. Pengoperasian aktuator pneumatik Suction Cup (SUCTION ON / OFF).
7. Pemantauan posisi koordinat Kartesian X, Y, Z, dan orientasi R secara real-time.
8. Fitur lanjutan Point-to-Point (PTP Move to XYZR) dilengkapi sistem pengaman 
   Software Limit Watchdog untuk mencegah overtravel dan tabrakan mekanis.

TUGAS 1. PEMERIKSAAN SISTEM ROBOT (HARDWARE)
--------------------------------------------------------------------------------
1. Identifikasi Komponen Hardware:
   - Base (Basis Robot)     : Penopang utama yang memuat motherboard pengendali, 
                              port USB, jack catu daya DC, dan Joint 1 (rotasi azimuth).
   - Joint Manipulator      : Robot memiliki 4 sumbu gerak (Joint 1 Base rotasi, 
                              Joint 2 Rear Arm pitch, Joint 3 Forearm pitch, 
                              dan Joint 4 Servo rotasi end-effector R).
   - Link Manipulator       : Lengan artikulasi aluminium alloy presisi tinggi 
                              (Rear Arm dan Forearm) dengan mekanisme paralel linkage.
   - End-Effector           : Suction Cup Kit yang dihubungkan ke selang silikon 
                              dan pompa vakum pneumatik terintegrasi pada base.
   - Catu Daya              : Adapter daya AC-DC 100-240V ke 12V DC / 7A.
   - Tombol E-Stop / Saklar : Saklar daya utama pada bagian belakang base Dobot 
                              sebagai pemutus tegangan darurat fisik.
   - Kabel Komunikasi       : Kabel USB 2.0 Tipe A-to-B penghubung Dobot ke port laptop.

2. Pengecekan Fisik dan Area Kerja:
   - Kondisi fisik manipulator bersih, bebas dari deformasi mekanis dan hambatan kabel.
   - Radius kerja robot sejauh 320 mm telah dikosongkan dari objek asing atau 
     penghalang untuk mencegah benturan selama proses kalibrasi homing.
   - Kabel catu daya DC 12V dan kabel komunikasi USB terpasang kokoh.

3. Identifikasi COM Port melalui Device Manager:
   - Akses Device Manager Windows (Windows + X -> Device Manager).
   - Buka grup "Ports (COM & LPT)".
   - Dobot teridentifikasi menggunakan chip komunikasi Silicon Labs CP210x USB to UART Bridge.
   - COM Port yang terdeteksi: COM3 (atau COM4 menyesuaikan port laptop yang aktif).
   - Baud rate standar komunikasi Dobot: 115200 bps, 8 Data bits, No Parity, 1 Stop bit.

     * msvcp120.dll, msvcr120.dll (Visual C++ 2013 Redistributable runtime)

2. Identifikasi Interpreter Python:
   - Mengingat berkas 'DobotDll.dll' dikompilasi dalam format 32-bit (x86 PE), maka 
     interpreter Python yang digunakan WAJIB Python versi 32-bit (Python 3.10 32-bit).
   - Pengujian arsitektur interpreter dilakukan via terminal:
     Perintah : py -3.10-32 -c "import struct; print(struct.calcsize('P') * 8)"
     Hasil    : 32 (Menandakan environment berjalan pada arsitektur 32-bit).

3. Verifikasi Komunikasi Serial SDK:
   - Program memanggil dType.load() untuk memuat pustaka DLL ke dalam memori.
   - Fungsi dType.ConnectDobot(api, "COM3", 115200) dieksekusi.
   - Nilai kembalian ConnectDobot adalah DobotConnect_NoError (0), menandakan SDK 
     berhasil membuka port serial dan membaca handshake firmware robot.

   │   ├── DobotDll.dll

   │       ├── style.css         -> Desain responsif mobile-first modern
   │       └── app.js            -> Logika kontrol, AJAX polling & touch event

2. Arsitektur Dual-Process (Pemisahan Backend Web & Driver Hardware):
   - Dikarenakan arsitektur threaded server web seringkali memicu konflik memory 
     concurrency pada pemanggilan DLL Ctypes yang bersifat un-thread-safe, 
     sistem dirancang dengan arsitektur dual-process decoupled:
     * Proses 1: dobot_tcp_receiver.py (Port 5005)
       Mengelola komunikasi perangkat keras serial secara eksklusif menggunakan 
       antrean antrian non-blocking, polling posisi pada frekuensi 10 Hz, 
       serta pengawasan batas koordinat (software safety limit).
     * Proses 2: server/app.py (Port 5000)
       Menyajikan aset web HTML5/CSS3 dan REST API endpoint JSON, berkomunikasi 
       dengan receiver melalui loopback socket TCP (127.0.0.1:5005).

3. Langkah Menjalankan Server:
   - Terminal 1 (Receiver Driver Robot):
     cd "3. Program"
     py -3.10-32 dobot_tcp_receiver.py
     Status: [INFO] TCP Server listening on 127.0.0.1:5005.

   - Terminal 2 (Flask Web Server):
     cd "3. Program"
     py -3.10-32 server/app.py
     Status: Flask berjalan pada http://0.0.0.0:5000 (HTTP 200 OK).

4. Deteksi Alamat IP Host:
   - Alamat IP Wi-Fi terdeteksi: http://192.168.0.161:5000 (atau IP DHCP Wi-Fi aktif).

     warna hijau: "CONNECTED (COM3)".

2. Pengujian Tombol DISCONNECT:
   - Pengguna menekan tombol "DISCONNECT".
   - Sistem memanggil dType.DisconnectDobot().
   - Status badge seketika berubah menjadi merah "DISCONNECTED".
   - Eksekusi tombol JOG saat status disconnected dinonaktifkan secara otomatis 
     oleh antarmuka frontend untuk keamanan.

3. Re-koneksi Sistem:
   - Tombol CONNECT ditekan kembali. Sistem terhubung ulang secara mulus tanpa 
     perlu me-restart backend server (Plug-and-Play recovery).

TUGAS 6. PENGOPERASIAN HOME, CONTINUOUS JOG, DAN SUCTION CUP
--------------------------------------------------------------------------------
1. Pengoperasian Kalibrasi Homing (HOME):
   - Area kerja dipastikan bersih. Tombol "HOME" ditekan pada layar smartphone.
   - Manipulator melakukan probing mandiri pada Joint 1, Joint 2, dan Joint 3 
     menuju limit switch internal, lalu berhenti pada titik referensi aman:
     X = 250.0 mm, Y = 0.0 mm, Z = 50.0 mm, R = 0.0°.
   - Status telemetri pada web menunjukkan nilai koordinat yang stabil.

2. Pengujian Continuous JOG Sumbu X, Y, dan Z:
   - Uji Sumbu X: Tekan dan tahan tombol "X+" -> Manipulator bergerak maju; lepaskan -> berhenti seketika.
                  Tekan dan tahan tombol "X-" -> Manipulator bergerak mundur; lepaskan -> berhenti seketika.
   - Uji Sumbu Y: Tekan dan tahan tombol "Y+" -> Manipulator bergerak ke arah kiri; lepaskan -> berhenti.
                  Tekan dan tahan tombol "Y-" -> Manipulator bergerak ke arah kanan; lepaskan -> berhenti.
   - Uji Sumbu Z: Tekan dan tahan tombol "Z+" -> Manipulator bergerak vertikal naik; lepaskan -> berhenti.
                  Tekan dan tahan tombol "Z-" -> Manipulator bergerak vertikal turun; lepaskan -> berhenti.
   - Presisi pergerakan terbukti linear tanpa deviasi berlebih pada sumbu non-aktif.

3. Pengujian Dua Variasi Kecepatan JOG:
   - Uji Kecepatan 1 (Kecepatan Rendah): Diatur nilai X = 5 mm/s, Y = 5 mm/s, Z = 5 mm/s.
     Hasil: Gerakan halus, presisi tinggi, sangat stabil untuk penempatan akurat.
   - Uji Kecepatan 2 (Kecepatan Sedang/Tinggi): Diatur nilai X = 20 mm/s, Y = 20 mm/s, Z = 20 mm/s.
     Hasil: Respons translasi lengan jauh lebih cepat dan dinamis tanpa kehilangan sinkronisasi pulsa motor.

4. Pengujian Aktuator Suction Cup:
   - Benda uji (kubus kayu ringan / akrilik 25x25 mm) ditempatkan pada alas kerja robot.
   - Lengan diturunkan menggunakan Continuous JOG Z- hingga bantalan silikon Suction Cup menyentuh permukaan benda.
   - Tombol "SUCTION ON" ditekan -> Pompa vakum Dobot aktif menghasilkan tekanan hisap negatif; benda terangkat sempurna.
   - Robot digerakkan naik (Z+) dan digeser (X+/Y+) memindahkan benda kerja.
   - Tombol "SUCTION OFF" ditekan -> Katup pelepas tekanan terbuka, pompa mati seketika, dan benda uji terlepas dengan presisi di posisi target.

================================================================================
E. ANALISIS HASIL PENGUJIAN DAN ASPEK KESELAMATAN KERJA
================================================================================

1. Analisis Arsitektur dan Komunikasi Jaringan:
   Penerapan model decoupling antara Flask Web Server dan TCP Hardware Receiver 
   terbukti sangat handal. Protokol HTTP/REST API ideal untuk pengiriman instruksi 
   diskrit (Connect, Disconnect, Homing, Suction, Speed Change), sedangkan polling 
   posisi real-time berjalan mulus melalui asynchronous fetch interval 100 ms. 
   Latensi pengiriman perintah dari smartphone melalui jaringan Wi-Fi lokal berkisar 
   antara 15 ms hingga 35 ms, yang berada jauh di bawah ambang batas human latency 
   (100 ms), sehingga respon continuous jog terasa sangat interaktif dan presisi.

2. Mekanisme Continuous JOG dan Penanganan Dead-Man Switch:
   Pada sistem mobile web, Continuous JOG diimplementasikan menyerupai tombol 
   "Dead-Man Switch". Ketika jari menyentuh tombol (event 'touchstart' atau 'mousedown'), 
   instruksi start JOG dikirim satu kali, dan ketika jari diangkat (event 'touchend' 
   atau 'mouseup') instruksi 'JOG STOP' seketika dieksekusi. Untuk mengantisipasi 
   kehilangan sinyal atau gangguan browser, receiver dilengkapi batas watchdog 
   software yang otomatis menghentikan pergerakan jika tidak ada pembaruan status 
   atau ketika batas software limit terlewati.

3. Software Limit Watchdog (Proteksi Perangkat Lunak):
   Untuk mencegah Dobot Magician mengalami overtravel atau menabrak base mekanik 
   sendiri, receiver menerapkan batasan koordinat perangkat lunak yang ketat:
   * Sumbu X : 150.0 mm s/d 300.0 mm
   * Sumbu Y : -150.0 mm s/d 150.0 mm
   * Sumbu Z : -50.0 mm s/d 150.0 mm
   * Sudut R : -135.0° s/d 135.0°
   Jika nilai koordinat aktual mendekati batas limit saat Continuous JOG berlangsung, 
   receiver secara otonom mematikan jog motion dan mengembalikan notifikasi peringatan.

4. Analisis Efektivitas Suction Cup:
   Aktuator Suction Cup yang dikendalikan oleh katup solenoid dan pompa udara vakum 
   terintegrasi mampu mencengkeram material datar (kayu/akrilik) dengan gaya angkat 
   yang konstan. Respon aktivasi pneumatic on/off sangat cepat (< 100 ms).

5. Prosedur Keselamatan Kerja (Safety Procedure):
   Pengoperasian robot manipulator mengikuti SOP standar industri:
   - Selalu menjaga jarak aman minimal 50 cm di luar amplop kerja maksimum robot.
   - Operator selalu siap siaga menekan tombol STOP pada antarmuka web atau 
     mematikan saklar fisik Dobot jika terjadi anomali lintasan.
   - Menggunakan kecepatan rendah (5 - 10 mm/s) pada awal pengujian lintasan.
